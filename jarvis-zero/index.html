JARVIS ZERO · A compact AlphaZero-inspired experiment: legal-move generator, policy/value learning, and Monte Carlo tree search. Pure Zero begins with zeroed learned weights and no opening book or pretrained data; playing a few games does not make it Grandmaster-strength. Tactical assist adds classical evaluation, so that mode is not from zero. The model is saved to this device, and Export brain creates your portable checkpoint.
Chess-piece artwork: Cburnett set distributed by Lichess, GPL-2.0-or-later, via the installed MetaPost mpchess-cburnett adaptation. This chess program is a personal local prototype, not affiliated with Chess.com or Lichess.
